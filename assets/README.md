# Imágenes opcionales de motos

La animación funciona sin archivos de imagen: cada motocicleta tiene una ilustración SVG integrada.
Si quieres reemplazar las ilustraciones, coloca PNG transparentes en esta carpeta con estos nombres:

- `moto1.png` — moto azul de la escena del jardín.
- `moto2.png` — moto magenta de la escena del jardín.
- `moto3.png` — moto celeste de la escena del jardín.
- `hotwheels.png` — imagen grande que aparece durante la secuencia.

Usa imágenes recortadas alrededor de la moto, con fondo transparente. La imagen grande puede ser
horizontal; las tres imágenes pequeñas se adaptan al espacio de cada moto. Si falta un archivo o no
se puede cargar, se conserva automáticamente la ilustración vectorial incluida.
